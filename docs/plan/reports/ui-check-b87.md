## Defects, ranked

1. MEDIUM, QX2: the "4 cars" limit message is out of sight where the click happens. Cars page, Table or Cards, scroll down, click "+" / "+ Compare" on a 5th car: nothing visible changes; "Compare holds 4 cars. Remove one first with − Compare." is a `.banner` at the top of `.browse-results`, 1452 px above the viewport in my run (scrollY 1744). Screen readers hear it (role=status) but a sighted user sees a button that silently does nothing. Expected: message next to the button, in a toast, or the button disabled with a visible reason. (On /charging the banner is 44 px under the button, fine.)
2. LOW, QX3: at 375 px the "Already in Compare" suggestion row squeezes the car name into a narrow column (name wraps over ~5 lines, row 160 px tall vs 64 px for normal rows) because the tag sits beside it. Look only; fix by stacking the tag under the name on phones.
3. LOW, touch targets on phones: card "+ Compare" toggle is 29 px tall, dialog Add to Compare / Cancel 36 px, dialog selects 31 px (table toggle and dialog X are 44). Same height as the existing `.btn small`, so consistent with the site, but below 44.
4. LOW, a11y: after removing a car with the card's Remove button on /compare, focus drops to the page start (document.body) instead of staying in the list; and the header "Compare (n)" link has no accessible name in the Browser tool's tree (text is present: innerText "Compare (3)"; probably tool quirk, not verified with a screen reader).

## Looks off, not in the brief
- On /compare the Settings panel, My car menu etc. are unaffected; page URL gains `?cars=` automatically after any change (existing behaviour).
- The table toggle on desktop is 32 px (per design-language B87); fine for mouse.
- Light theme slot 4 ghost/lane is grey, not a hue (design palette, noted so it isn't mistaken for a bug).
