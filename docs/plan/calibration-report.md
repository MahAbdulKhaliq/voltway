# Template calibration report (checklist 2.2)

**Approved by the owner on 2026-11-16 (B41).** The proposed numbers below are now in `TEMPLATES`. This file is the snapshot they were tuned from; re-running `npm run calibrate` overwrites it with a new comparison starting from the approved numbers.

Generated by `npm run calibrate` on 2026-11-16 from the data build (84 variants). Target (charging-curve-viewer.md §9): most cars within ±15 % on 10–80 % time.

**How it works.** Each car with a DC peak, a battery size and a reference gets the template estimate (template × DC peak). The reference is its measured curve's 10–80 % time (same battery figure), or else its published 10–80 % time. Weights: tested curve 3, community curve 2, published tested 2, published community 1.5, manufacturer curve or claim 1; halved when a measured curve does not cover 10–80 % (B24). Variants with identical inputs and reference count once. Tuning moves the 30/50/70/80 % fractions in 0.01 steps to cut the weighted error (a Huber loss on the log error: squared within ±15 %, linear beyond, so a single odd reference cannot drag a whole template), with a small pull toward the starting shape, keeping the peak at 10 % and the curve falling after it. 0, 10, 90 and 100 % stay as they are (they don't change a 10–80 % time).

**Error** is the estimate against the reference: +20 % means the estimate is 20 % slower than the reference.
